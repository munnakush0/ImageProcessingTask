
# Image Processing Mini Projects

This repository contains the deliverables for three mini tasks related to basic image processing using Python and OpenCV.

## 📁 Tasks Overview

### ✅ Task 1: Basic Image Manipulation
- Converted an image to grayscale
- Applied Gaussian blur
- Detected edges using Canny edge detector
- 📄 Report: `Task1_Image_Processing_Summary_Report.pdf`

### ✅ Task 2: Color Detector (Webcam)
- Opened webcam feed and detected BGR pixel color on click
- Displayed color info on the webcam window and console
- 📄 Report: `Task2_Color_Detector_Summary_Report.pdf`

### ✅ Task 3: Technical Documentation
- Summary of what was built, challenges faced, and potential improvements
- 📄 Report: `Task3_Technical_Documentation_Report.pdf`

## 🚀 How to Run Code
Make sure Python and OpenCV are installed:
```bash
pip install opencv-python
```

Run the scripts from terminal:
```bash
python image_processing.py       # for Task 1
python color_detector.py         # for Task 2
```
